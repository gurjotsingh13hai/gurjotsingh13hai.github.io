Privacy policy

SD-SI · effective 24 October 2026

SD-SI is a private, internal tool used by one immigration practice in Canada. Only the practice's own Google account signs in to it. This page explains what it does with data from Google.

What data it uses

  • Google Drive. It lists, reads and downloads files in the practice's own Drive: the client folders the staff have prepared and a folder of reference examples. It uploads the finished package into the same client folder, creates folders, and creates and removes small marker files that show a folder is being worked on.
  • Gmail (send only). It sends short emails from the practice's account to the practice's own staff, for example to say a package is ready for review or that a document is missing. It cannot read, search or delete any email.
  • Google Sheets. It adds rows to a run log sheet in the same Drive.

How the data is used

The data is used only to prepare application packages for the practice's own clients and to tell the practice's staff about the work. The files in Drive belong to the practice and its clients and are handled under the practice's professional duties.

To do the work, copies of the files are processed in a private, temporary work space in the cloud, with the help of an AI model (Claude, by Anthropic) used under the practice's own account. The temporary copies are deleted at the end of each run. SD-SI keeps no database of its own: the files stay in the practice's Drive.

Sharing

Data from Google is not sold, rented or used for advertising. It is not shared with anyone except the services needed to do the work described above (Google, and Anthropic for processing) and the practice's own staff.

AI models

Data from Google is not used to develop, improve or train generalized AI or machine-learning models.

Google API Services User Data Policy

SD-SI's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Security

SD-SI's access keys are kept only in the practice's private settings, never in its code. It cannot delete files: the only thing it moves to Drive's trash is its own marker file. Access can be withdrawn at any time from the Google account's security settings (Third-party connections).

Keeping and removing data

Files stay in the practice's Google Drive until the practice removes them. Temporary working copies are deleted at the end of each run. To ask about any data, write to the contact below.
